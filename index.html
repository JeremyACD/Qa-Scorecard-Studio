QA Scorecard Studio Prototype
How this differs from the original tool. Scorecards are data, not code. The renderer has no branch for any specific call type: it draws whatever the config hands it. A QA lead adds a call type or changes a question in the builder, publishes it, and the scoring form changes on the next load. No engineer, no deploy.

Prototype shortcuts. Config and evaluations live in browser storage on this device. There is no authentication, so anyone can log coaching as anyone. Nothing is exported to a warehouse. Those are Part 4 items.
